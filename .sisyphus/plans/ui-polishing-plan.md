# 📜 禅意空间：质感升维计划 (UI Polishing Plan)

## 🎯 核心目标
在不改动 HTML 结构的前提下，通过微调 CSS Tokens 和组件样式，将界面从「干净的网页」提升至「具有物理质感的数字纸质书」。

## 🛠️ 实施阶段 (Phases)

### 第一阶段：底层 Token 升维 (The Foundation)
**目标：** 建立更真实的物理光影基准。
- **多重阴影系统 (Layered Shadows)：** 将单一阴影升级为 3 层叠加阴影，模拟真实光线在纸张上的弥散效果。
- **纸质层级色彩：** 微调 `--bg-base` 与 `--bg-card` 的对比度，引入极其微弱的色彩偏移，增强空间的纵深感。
- **高光定义：** 新增 `--edge-light` 变量，用于模拟卡片顶部的物理反光边。

### 第二阶段：呼吸感与律动审计 (The Breathing)
**目标：** 消除视觉上的“微小违和感”，建立严格的 8px 律动。
- **间距标准化：** 审计全站所有 `padding` 和 `gap`。将所有硬编码的数值（如 `20px`, `12px`）全部替换为 `var(--spacing-*)`。
- **排版微调：** 优化 `.reading-text` 的行高与段间距，确保在不同屏幕尺寸下都具有完美的文学阅读节奏。
- **对齐校准：** 统一所有卡片、列表项的圆角半径，确保视觉语言的绝对一致性。

### 第三阶段：全页面组件打磨 (The Details)
**目标：** 针对不同页面的核心组件进行“手术刀式”优化。
- **首页 (Home)：**
    - `Hero Card`：将两色渐变升级为三色“丝绸渐变”。
    - `Book Cover`：优化封面阴影，增加立体感。
- **书籍详情页 (Detail)：**
    - `Detail Hero`：增强背景与前景的层级分离感。
    - `CTA 按钮`：优化主次按钮的对比度与圆角质感。
- **阅读页 (Reader)：**
    - `沉浸式模式`：优化顶底栏切换的淡入淡出曲线。
    - `正文首字`：优化首字下沉 (Drop Cap) 的色彩与间距。
- **分类与搜索页 (Category/Search)：**
    - `列表项`：优化 Hover 状态的背景色，使其更像“光影掠过”而非简单的颜色填充。

### 第四阶段：微交互与灵魂注入 (The Soul)
**目标：** 将“机械感”转化为“有机感”。
- **软压反馈 (Soft-Press)：** 将全站的 `scale(0.95)` 统一改为 `scale(0.98)`，并同步缩减阴影偏移，模拟真实物理按压。
- **有机过渡 (Organic Motion)：** 将简单的 `ease-out` 升级为自定义的 `cubic-bezier(0.2, 0.8, 0.2, 1)`，使动画具有惯性和弹性。
- **玻璃质感优化：** 增强 `.glass-warm` 的模糊度与顶部高光边框，提升精致度。

### 第五阶段：主题和谐度验收 (The Harmony)
**目标：** 确保 Night 和 Sepia 主题在升级后依然完美。
- **深色模式阴影：** 调整 Night 主题的阴影颜色，避免在黑色背景下出现死黑块。
- **护眼模式对比度：** 确保 Sepia 主题在提升质感后，依然保持极高的阅读舒适度。

---

## 📈 验收标准 (Success Criteria)
- [ ] **无结构破坏：** 0 处 HTML 标签改动。
- [ ] **一致性：** 所有页面的交互反馈（Hover/Active）逻辑统一。
- [ ] **质感提升：** 视觉上能明显感觉到“纸质感”和“光影深浅”的增强。
- [ ] **性能零影响：** 仅通过 CSS 变量和类名优化，不增加额外的 JS 开销。
